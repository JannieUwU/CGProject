# 第三项反馈：MSAA 实现与验证

本文汇总当前三角形 MSAA 几何选点、后续减少重复计算的优化、开发阶段实验和已知局限。操作方法见 [第三项指南](第三项反馈-改动说明与查看指南.md)，共享边与 16 位几何见 [第二项技术说明](第二项反馈-共享边规则与验证.md)，构建与运行见 [README](../README.md#桌面构建与验证)。

本文按三个阶段呈现实验：第二项 16 位打磨完成版、首次完成 MSAA 几何选点的版本、此后减少重复计算的当前版本。每组数字注明各自基线与条件，分别说明相应阶段的效果。查看当前功能只需构建当前源码。

当前修改覆盖本体、云层和环带三角形。第一项真实记录、第二项共享边、逐层手动展开、重复选择保留状态和局部打磨均保留；独立大气射线与轨道策略不变。土星两项阴影过滤暂不实施。

## 改出来是什么

以前，同一三角形在一个像素里，哪个样本先通过深度测试，就在哪里计算一次颜色；其他合格样本共用它。前面的物体挡住一个样本，可能连没有被挡住的部分也跟着换颜色。

现在先按三角形的几何覆盖决定“在哪里算颜色”，深度测试决定“哪些样本能使用这份颜色”。例如四个样本都落在后方三角形里，左上样本后来被前面的物体挡住，后方三角形仍在像素中心计算颜色，再写给剩下的样本，不会改到右上样本重新取色。全部被挡住时不调用着色函数。

这主要消除由深度通过顺序引入的额外变化，并减轻总从左上等固定样本取色的偏向。同一三角形片段仍共享一次着色，像素内的细纹理和透明度变化由这次结果近似表达；SSAA 则逐样本计算颜色。

## 明确的选点规则

| 优先级 | 采用的位置 | 采用条件 |
|---|---|---|
| 1 | Pixel center，像素中心 `(0.5, 0.5)` | 中心属于当前三角形，透视插值有效；云层还需朝向检查通过 |
| 2 | Coverage centroid，全部几何覆盖样本的位置平均值 | 中心不可用，平均点的插值与云层朝向检查通过 |
| 3 | Covered sample fallback，固定几何后备样本 | 前两者不可用，从全部几何覆盖样本中选择有效且离中心最近的一个；等距离按固定样本编号 |
| 无有效点 | 不调用着色函数、不写入该片段 | 所有候选都无效，记录具体失败状态 |

这里的平均点是**离散采样位置的平均值**。先平均屏幕空间的仿射重心权重，再进行一次透视校正，得到该位置的 UV、法线等属性并计算颜色。三个样本的平均点可以是 `(5/12, 5/12)`，直接保留该位置参与计算；16 位网格用于投影顶点与覆盖判断。

区分三个集合：G 是全部几何覆盖样本；D 是通过深度测试及必要的逐样本有效性/云层朝向检查、能接收着色结果的样本；W 是颜色实际写入的样本。位置由 G 和几何属性确定。D 决定是否执行着色及哪些样本可以接收结果，W 记录实际写入情况；D 为空时跳过着色调用。

后备位置允许落在一个已被遮挡的样本上，用于计算共享颜色；该样本的可见性继续由自身深度测试决定。每个接收样本继续使用自己的深度、拾取 UV 和混合底色。零 alpha 仍算一次真实调用，记录为 Transparent，该片段保留这次调用结果。每个裁剪后三角形片段在一个像素里最多调用一次；整个像素的着色次数由各图元和效果累计而成。

实现中，四个角样本全部覆盖时由凸性确定中心也在覆盖内，平均其仿射权重获得中心属性，省去额外的大整数边函数查询。覆盖和插值依然使用第二项的统一几何，未改变边界归属、网格精度或采样位置。

## 在界面中怎么看

1. 按 README 构建并打开当前程序，进入行星近景，选择 `4× MSAA` 和 `Inspect`，点选一个像素。
2. 手动展开 `Details → Processing history`，选中一个本体、云层或星环三角形事件。
3. 在原有 `Shading and depth values` 中看实际坐标、`Location rule`、共享颜色和接收样本。必要时显示 `Center not used`、`Centroid not used` 的原因。
4. 中心着色时菱形通常位于四个采样圆点之间；平均点也可以位于圆点之间。菱形标记实际着色位置，四个圆圈标记覆盖采样位置。没有调用时不画菱形，零 alpha 调用仍有记录。
5. 大气事件显示 `First eligible ray sample`，普通采样及 SSAA 显示 `Sample position`。大气沿用独立射线规则。

原有默认收起、关闭父层重置后代、换像素/星球/模式重置，以及重复点当前近景星球保留分析状态的规则继续有效。

## 正确性验证

新增 `planet_msaa_shading_tests`，直接使用生产光栅器和受控屏幕几何，检查：

- 中心、单样本与多样本平均点、三个真实覆盖样本的有理数平均点，以及顶点六种排列。
- 中心/平均点的背面与无效插值后备；固定编号决胜，不依赖遍历先后或深度掩码。
- 16 种逐样本遮挡组合：G 不变时共享位置与颜色不变；完全遮挡为零次调用。
- 后备选中的样本自身被遮挡时，其他有效样本仍使用同一几何选点。
- 非共面、不同深度的两个不透明三角形交换提交顺序。后方使用高变化但 alpha 为 1 的程序化环材质，以确实暴露旧问题：旧版出现 1 个不同像素，新版为 0；检查条件为 alpha 为 1、深度不同的两个三角形。
- 独立公式计算透视校正属性、实际着色 RGB、各样本深度与最终拾取 UV，防止错误共享深度或 UV。
- 零 alpha 只调用一次、无写入；正常透明混合按各样本原底色回放。
- 过程记录开启/关闭时图像、拾取和着色次数一致；逐事件回放还原最终颜色。

原有共享边、六处云层回归、UI 展开和重复点击、测速等测试及原图像断言均继续保留。

结果：Release 桌面构建通过，CTest **9/9 通过**。专项构建中的生产光栅器、覆盖实现及新增测试通过 AddressSanitizer、UndefinedBehaviorSanitizer 和 float-cast-overflow 检查，所链接的其余核心静态库沿用常规构建。

实际桌面窗口也核对了中心菱形、坐标与 `Location rule: Pixel center` 的换行展示；点选像素后 Details 默认收起，Processing history 与下级仍需手动打开，关闭 Details 再打开会收起历史和更深层，换像素收起 Details。重复点 Earth 保留当前像素、打开的着色详情与已有测速结果。

这一组比较“第二项 16 位完成版 → 首次几何选点版本”。环境为 Apple Silicon、macOS 14.6.1、Apple Clang 15、Release 构建。每项预热两次、七次渲染取中位数，关闭过程记录，新旧交替三轮，再取轮次中位数；不含 PNG 写入。

## 后续优化：减少重复计算

后续先用调用栈与独立诊断定位开销。基线金星斜视的 8,443 个主线程调用栈样本中，约 48.2% 落在光栅三角形函数（含内联代码），9.3% 在属性插值，15.6% 在 pow。诊断计数表明，地球与金星相关场景约七成候选包围框像素没有覆盖，云层还会重复计算接收样本的属性。探针用于定位开销，正式提速结果采用关闭探针后的独立计时。

实际只做两类等价计算优化：

| 改动 | 保持结果的条件 |
| --- | --- |
| 不预先清零全部权重，并延后准备完整样本属性 | 覆盖成功会写满权重，只读取掩码有效项；至少一个样本通过深度后才准备完整属性 |
| 云层接收样本复用已算出的透视深度 | 使用同一位置、同一权重得到的 double 值，保留属性表达式和运算顺序 |

优化保留原有选点、共享边、逐样本深度/UV、混合、透明度和有效性规则，以及过程记录内容和判断阈值。

### 优化前后的一致性

32 张静态图和 84 帧运动图的 RGB 与逐字段序列化状态一致。状态包含全图拾取 ID、UV、表面变化标记、着色计数，以及每帧选中像素的初始状态、事件、实际着色位置/原因、混合和最终状态，不比较耗时。另有 8 个土星选点 × 21 帧，共 168 份完整记录与诊断属性一致。

一致性检查在相同机器和构建配置下进行：图像及拾取等状态覆盖全图，完整过程记录覆盖每帧指定的选中像素。

### 五轮正式计时

这组比较“首次几何选点版本 → 后续计算优化版本”，使用无探针程序、相同固定快照，关闭详细记录。八场景四方法共 32 个组合，每次预热两次、七次 CPU 渲染取中位数；重复五轮，交换版本先后并轮换场景顺序。

“前/后”分别是五轮中位数；耗时变化由两者计算，配对变化是每轮新旧比值的中位数。负数表示耗时下降；帧率与单帧耗时互为倒数。

|---|---:|---:|---:|---:|---:|
| 地球 320×240 | 49.562 | 46.890 | −5.39% | −4.40% | 5/5 |
| 土星 320×240 | 14.367 | 13.840 | −3.67% | −3.68% | 5/5 |
| 轨道 320×240 | 3.867 | 3.911 | +1.12% | +0.89% | 2/5 |
| 地球斜视 640×480 | 194.146 | 185.510 | −4.45% | −4.26% | 5/5 |
| 金星斜视 640×480 | 126.231 | 120.289 | −4.71% | −4.66% | 5/5 |
| 天王星斜视 640×480 | 59.902 | 58.731 | −1.95% | −2.07% | 5/5 |
| 土星极近景 320×240 | 36.063 | 34.767 | −3.59% | −3.72% | 5/5 |
| 近裁剪环带 320×240 | 16.409 | 14.966 | −8.79% | −8.42% | 5/5 |

七个三角形 MSAA 场景均为 5/5 轮更快，中位耗时下降约 2%–9%。纯轨道沿用原计算路径，本组测得耗时增加约 1.1%。

普通/SSAA 控制中，地球 Single 首批出现 +5.85%，地球斜视 Single 出现 −3.17%，因此单独进行七轮复测，保留同场景 MSAA 作为对照：

| 地球 MSAA | 48.704 | 46.597 | −4.33% | −4.65% |
| 地球斜视 Single | 98.772 | 99.047 | +0.28% | +0.22% |

地球 Single 首批约 5.9% 的耗时增加，在独立复测中缩小到表中约 0.5%；同场景 MSAA 仍为 7/7 轮更快。两批结果共同呈现控制项波动。后续计算优化与首次几何选点采用各自的计时批次和比较基线，结果分别呈现。

## 土星残余跳变：已定位，暂不改画面

固定土星 320×240 快照，缩放为 `0.999 + 帧号 × 0.0001`，检查 21 帧。下表 RGB 为显示值，坐标从 0 开始；阴影比例属于着色内部量，不与显示 RGB 直接混算。

| 位置与帧号 | 最终 RGB 变化 | 首个主要变化及归因 |
| --- | --- | --- |
| `(126,130)`，18→19 | `199,180,155 → 153,138,119` | 本体几何覆盖从右上/右下变成仅右上，平均点 `(0.75,0.5) → (0.75,0.25)`；环影遮光量约 `0.051 → 0.823`，细密阴影放大了位置变化 |
| `(119,135)`，9→10 | `111,99,81 → 154,137,113` | 本体覆盖仍是右上/右下，但中心跨出三角形，代表点从中心变为 `(0.75,0.5)`；环影遮光量约 `0.820 → 0.052` |
| `(224,133)`，13→14 | `25,26,26 → 58,57,54` | 环带四样本覆盖、中心位置、透明度及混合底色不变，本体遮光判断从有变无，原有可见度从 `0.025 → 1` |

前两个点的大幅变化首先发生在球面，来源是着色位置与细密环影的共同变化。第一个点的样本由相邻三角形各自唯一认领，拼接覆盖完整。第三个点来自原有硬阴影边界，需要通过阴影过滤进一步处理。临时去掉相应阴影的诊断结果支持上述归因，正式渲染继续使用原阴影规则。

观察样本同时包含跳变点、安静点 `(160,110)` 和改善点 `(118,129)`、`(126,124)`。当前已检查原尺寸关键帧，连续播放的主观观感验收待补充。

这类局部跳变保留为后续优化项。可研究按像素投影范围平均环影遮光量，以及按遮挡比例过滤环带硬阴影边界。这两项会调整画面规则，预期让细阴影变柔和，也会增加计算量，需要结合画质与耗时评估。
