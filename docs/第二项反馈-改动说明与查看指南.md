# 第二项反馈：改动说明与查看指南

更新时间：2026-11-21。

本文介绍了第二项“共享边的唯一归属”的实际改动、查看方法和演示例子。当前程序已包含 16 位精度打磨、重复点击修复和第三项的新 MSAA 选点规则；本指南区分各项作用。

## 1. 这次做了什么

星球表面和星环由许多三角形拼成。两个三角形共用一条边时，恰好落在这条边上的采样点需要明确归谁处理。以前使用统一容差，两边可能同时说“这个点也算我的”；现在统一规则，让真正共享的边界样本归其中一侧。

| 改动 | 现在怎样处理 | 带来的好处 |
| --- | --- | --- |
| 采用 top-left 规则 | 按统一的包含/排除约定，判断边界上的采样点属于哪一侧 | 共享边不再由两侧重复认领，覆盖记录更明确 |
| 三角形采样方式使用同一规则 | 普通单采样、4× SSAA、4× MSAA、离线 16× SSAA 都使用它 | 比较方法时，边界归属口径一致 |
| 使用统一的 16 位子像素网格 | 覆盖与属性插值基于同一套细网格几何 | 减少两套几何不一致，减轻初版较粗网格的局部副作用 |
| 统一近裁剪交点计算 | 同一条边从两个方向提交，采用一致的交点计算方式 | 减少镜头近处裁剪后接缝不一致的风险 |
| 按坐标大小选择精确计算路径 | 普通坐标快速算，巨大坐标使用适合的精确后备 | 不靠放宽容差或丢掉巨大三角形来处理特殊情况 |
| 补充重复点击修复 | 已在某颗星球近景时，再点同一个名称保留当前分析状态 | 不重新进入近景、不清空像素选择和有效测速 |

第二项主要改善规则的正确性与一致性；同阶段还补充了重复点击的交互修复。

## 2. 适用版本与运行入口

先按 [README 的桌面构建与验证](../README.md#桌面构建与验证) 构建当前源码，再使用其中的启动命令。说明统一使用项目根目录下的 `build`，不依赖个人工作目录或旧预览应用包。

当前程序累计包含三项反馈。本文引用的“第二项前后”数据来自开发阶段单独控制变量的实验，用于分析共享边修改的影响。

## 3. 如何进入并查看

1. 打开当前程序，选择地球或土星，等待镜头进入近景。
2. 开启顶部 `Inspect`，选择 `1x`、`4× SSAA` 或 `4× MSAA`，点击想检查的像素。
3. 在右侧 `Pixel` 中先看 `Pixel zoom`，再手动展开 `Details → Processing history`。
4. 使用 `Record … of …` 切换三角形记录，查看覆盖数、深度通过数、写入数和采样点示意图。
5. 有疑问时展开 `Shading and depth values → Sample … details`，区分“没有覆盖”和“覆盖了但被挡住”。
6. 使用 `Compare` 并排比较当前版本中的两种采样方法。

共享边规则通过真实覆盖记录中的 Covered 结果体现。精确落在公共边上的样本适合用第 6 节的受控例子和自动检查来观察，能够直接核对唯一归属。

比较视图中的详细记录来自实际点击的一侧，左右放大图同步位置。`Region` 控制放大范围，采样数量由所选方法决定。

## 4. 第二项和其他两项有什么区别

| 项目 | 回答的问题 | 主要体现在哪里 |
| --- | --- | --- |
| 第一项：过程记录 | “这个像素经历了哪些处理？” | Details 中能查看真实过程 |
| 第二项：共享边规则 | “这个边界采样点到底归哪个三角形？” | Covered 的归属与几何计算 |
| 第三项：MSAA 选点 | “这次共享颜色应该在哪里计算？” | 实际着色位置及 Location rule |

第二项完成时，MSAA 仍使用首个合格样本着色。当前累计版本已由第三项改为中心优先、几何覆盖平均点、固定后备。当前程序中的中心菱形体现第三项的选点规则。

## 5. 每一项是什么意思

| 名称 | 用人话理解 |
| --- | --- |
| 共享边 / 公共边 | 两块相邻三角形拼在一起的接缝，两边使用同样的端点。 |
| top-left | 按“上/左边包含、下/右边排除”的统一约定处理边界采样点，让相邻三角形的共同边界归一侧。斜边也由统一方向规则判断。 |
| 覆盖 Covered | “这个三角形在几何上有没有盖住这个检查点？”这是遮挡之前的问题。 |
| 深度测试 Depth test | “盖住以后，会不会被更近的东西挡住？”覆盖先决定归属，深度测试再决定可见性。 |
| 写入 Color writes | “这次真的更新颜色了吗？”覆盖后还可能因为遮挡、透明度或其他检查而不写入。 |
| 16 位子像素网格 | 把一个像素的边长细分成 65,536 份，用同一把细尺子表示投影顶点。该精度用于几何位置计算，采样数量和图像色深分别由各自设置决定。 |
| 插值 | 根据三角形三个顶点，计算中间位置的深度、纹理坐标、法线等属性。 |
| 近裁剪 | 三角形太靠近相机或穿过相机近处边界时，先切出可绘制的部分。 |
| 精度打磨 | 从初版 8 位网格改为 16 位，减少细小位置取整对云层等敏感效果的影响。 |

普通单采样仍检查像素中心；4× SSAA 与 4× MSAA 仍使用像素内原来的四个位置。提高几何精度不会把 MSAA 变成更多采样，也不会改变圆圈的数量。

## 6. 用一个例子串起来

下面用自动检查中的拼接矩形说明规则。

把一个正方形沿左上到右下的对角线拆成两个三角形。现在检查一个横跨这条对角线的像素，里面有四个采样点：

```text
像素内：x 向右，y 向下

       1 ●          ● 2
           ╲
              ╲       共享的对角线经过 1 和 4
                 ╲
       3 ●          ● 4
```

实际受控矩形的端点为 `(0,0)、(4,0)、(4,4)、(0,4)`，观察像素 `(2,2)`。四个采样点的局部位置与真实覆盖检查结果如下：

| 样本 | 像素内位置 | 第一项版本被几块三角形认领 | 第二项版本被几块三角形认领 |
| --- | --- | ---: | ---: |
| 1 | `(0.25,0.25)`，在接缝上 | 2 | 1 |
| 2 | `(0.75,0.25)` | 1 | 1 |
| 3 | `(0.25,0.75)` | 1 | 1 |
| 4 | `(0.75,0.75)`，在接缝上 | 2 | 1 |

这张表统计深度测试之前的几何覆盖。共享边规则在覆盖阶段就让接缝样本只归属一侧。

对于不透明表面，旧版深度测试可能挡掉重复处理，所以画面差异较小；统一归属让覆盖阶段本身更明确。对于透明表面，这一规则还能减少接缝处的额外混合，受控拼接测试检查覆盖和写入各一次。

按 README 完成桌面构建后，从项目根目录运行已有专项检查：

```sh
ctest --test-dir build -C Release -R '^planet_shared_edge_tests$' --output-on-failure
```

这个命令自动检查大量共享边情况。观察真实星球时，先找到共享同一条边的相邻三角形，再比较样本归属；前后表面、云层和大气会各自产生处理记录。

## 7. 展开、收起与重复点击规则

| 操作 | 当前累计版本的预期表现 |
| --- | --- |
| 开启检查并选中像素 | 自动进入 Pixel，Details 仍默认收起 |
| 收起上一级再打开 | 它的全部下级恢复收起，同级分支不受影响 |
| 换像素、换星球或换采样方式 | Details 及全部后代收起，记录选择重置 |
| 已在某颗星球近景，再点同一个名称 | 不重复飞入，不清掉像素、Inspect/Compare、详情或有效测速 |
| 从总览选择星球、选择其他星球 | 继续执行正常的镜头切换流程 |
| 主动点击 Reset view | 继续执行原有重置行为 |

点击名称进入星球近景沿用原有功能。本阶段修复重复选择当前近景星球时的多余重入，使分析状态继续保留。

## 8. 建议怎样演示

按“接缝例子 → 实际记录 → 操作稳定性”的顺序即可。

1. 用第 6 节的表说明：接缝上的点以前可能两边都认领，现在只有一边认领。重点展示接缝样本的归属变化。
2. 打开地球或土星的 Pixel 记录，解释 Covered、Passed depth、Color writes 分别代表覆盖、遮挡和实际写入。三个数量分别统计。
3. 展开到某个 Sample details，然后再次点击当前星球名称，展示像素选择与详情仍然保留。
4. 收起上一级或切换像素，展示下级恢复收起，证明第一项的交互规则也保留。
5. 被问到精度打磨时，用“一把更细的尺子，减少敏感位置的取整扰动”解释；详细整数实现留给技术报告。

## 9. 已验证的内容与范围

以下分别汇总开发阶段的精度实验和当前代码的自动检查。公开测试入口可直接运行；历史多版本图像与性能实验保留当时的条件和结果。

- 第二项阶段 Release 桌面构建及 8 项测试通过；当前累计版本的 9 项测试也已通过。两个数字属于不同阶段。
- 648,000 次矩形采样检查中，共享边没有重复认领或漏认领；另检查不同绕序、提交顺序、近裁剪、透明拼接、退化和巨大坐标。
- 16 位打磨相对同采样方式的 20 位几何精度参照，32 张静态图中明显差异像素实例由初版 8 位的 71 降至 2，84 帧运动序列由 406 降至 0。“明显差异”指任一显示通道差超过 8/255，该参照采用更细的几何网格，属于数值近似。
- 这里的“20 位”指几何网格精度，各图保持原采样方法；SSAA16 则指每像素采用 16 个采样点。
- 第一项记录回放、手动展开、换目标重置和重复点击保留状态的检查继续保留。
- 已完成 macOS / Metal 构建及界面验证，Windows / Linux 原生 GUI 待验证。

规则适用于两侧共用同一条边的几何；输入模型中的裂缝、重叠或 T 形接缝需要在模型层处理。16 位量化仍有有限误差，局部画面和耗时变化见验证表。

详细规则、精度选择、局部改善及性能代价已合并到 [共享边规则与验证](第二项反馈-共享边规则与验证.md)。继续查看 [第三项改动说明与查看指南](第三项反馈-改动说明与查看指南.md)。
