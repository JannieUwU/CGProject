# 基于软件光栅化的交互式太阳系可视化与抗锯齿分析

本项目使用 C++ 实现 CPU 软件光栅器，以太阳系、行星近景和环带为场景，比较单采样、SSAA 与 MSAA，并通过真实像素记录解释覆盖、遮挡、着色和颜色合成。Metal 或 OpenGL 负责显示 CPU 生成的图像和桌面界面。

## 当前功能与阅读入口

当前实现包含三项反馈及后续修复：

1. **真实像素过程记录。** 在 `Pixel → Details → Processing history` 中查看实际覆盖、深度测试、着色位置、透明混合和写入。各级手动展开，收起父层或更换目标时重置下级。
2. **共享边归属。** 所有三角形采样方式共用 top-left 规则和 16 位子像素几何，配合一致近裁剪及分级精确整数计算。
3. **MSAA 几何选点。** 三角形共享颜色优先在合法中心计算，必要时使用完整几何覆盖平均点或固定后备；逐样本深度、拾取 UV 和混合底色保持独立。

已修复重复点击当前近景星球时的多余重入，保留像素选择、Inspect/Compare、展开状态和有效测速。后续减少了无用属性准备与云层重复深度计算。土星仍有细密环影与硬阴影边界的局部跳变，两项阴影过滤暂不实施。

## 构建与运行

所有命令从项目根目录执行，路径中的 `build` 是本说明统一采用的桌面构建目录。需要 CMake 3.21 或更高版本、C 编译器、支持 C++17 的编译器及平台图形开发环境。首次配置会获取 nlohmann/json、REBOUND 5.0.1、Dear ImGui；没有已安装 GLFW 时还会获取 GLFW，因此需要可访问依赖下载地址。

macOS 使用 Xcode 命令行工具和系统 Metal；Linux/Windows 桌面端使用 OpenGL 及相应窗口系统开发环境。下面的 `./build/...` 启动方式用于 macOS/Linux 的单配置构建。

### 桌面构建与验证

```sh
cmake -S . -B build -DPLANET_BUILD_DESKTOP=ON -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --parallel 6
ctest --test-dir build -C Release --output-on-failure
```

桌面配置注册 11 项测试，包括核心渲染、像素记录、共享边、MSAA 选点、行星外观、批量导出和桌面状态/渲染/文档测试。构建目录与源码位置绑定；更换机器或源码目录后重新配置即可。

构建完成后启动桌面端：

```sh
./build/planet_studio
```

使用 Windows Visual Studio 等多配置生成器时，构建与测试命令仍带 `--config Release`、`-C Release`；程序通常位于 `build/Release/planet_studio.exe`。以下其他可执行程序也需按生成器采用对应的子目录和 `.exe` 后缀。Windows GUI 待进行原生环境验证。

### 仅构建命令行版本

不需要桌面界面时使用独立目录，避免改变已有桌面配置：

```sh
cmake -S . -B build-headless -DPLANET_BUILD_DESKTOP=OFF -DCMAKE_BUILD_TYPE=Release
cmake --build build-headless --config Release --parallel 6
ctest --test-dir build-headless -C Release --output-on-failure
```

此配置注册 8 项非桌面测试。下文导出命令也可将可执行程序所在的 `build` 改为 `build-headless`。已有依赖源码时可通过 CMake 的本地 FetchContent 源码配置复用；REBOUND 另支持 `REBOUND_SOURCE_DIR`，均须指向真实存在且版本兼容的源码目录。本说明不依赖开发者个人机器的路径或预览应用包。

## 命令行导出与离线采样对比

桌面构建同时生成命令行程序 `planet_sandbox` 和 `planet_aa_benchmark`。先查看参数：

```sh
./build/planet_sandbox --help
./build/planet_aa_benchmark --help
```

导出一张地球 MSAA 图像及场景状态，使用小分辨率便于快速检查：

```sh
./build/planet_sandbox --body earth --sampling msaa4 --width 320 --height 240 --output build/example-earth-msaa4.ppm --state build/example-earth-state.json
```

该命令生成 PPM 图像与 JSON 状态；再次使用相同文件名会覆盖示例输出。`--sampling` 接受 `single`、`ssaa4`、`msaa4`；兼容参数 `--samples 1|4` 对应单采样或 SSAA4，一次调用只选择其中一种参数写法。`--config` 可读取已存在的项目 JSON，`--time` 指定模拟时刻，`--body` 指定场景中存在的行星。

批量导出固定的地球、土星和轨道场景：

```sh
./build/planet_aa_benchmark --output-dir build/aa-example-001 --width 320 --height 240
```

每次导出使用一个新目录；目录已存在时，程序会提示更换名称。每个场景生成 Single、SSAA4、MSAA4、SSAA16 PNG 与边缘掩码，并导出 `metrics.csv` 和 `project.json`。这些结果由命令自动生成。SSAA16 提供离线的更密采样近似参考；桌面菜单提供 Single、SSAA4 和 MSAA4。

批量导出的误差按显示图像反解 gamma 2.2 后的线性 RGB 计算；每种方法预热一次，记录随后一次 CPU 渲染耗时，不含 PNG 写入。该命令用于固定场景的离线导出和初步比较。技术说明中的历史多轮交替实验采用各表注明的计时方法，桌面 Compare 则用于交互查看当前画面。

## 桌面查看与交互

### 行星设计与模拟

新增固定窗口的三维轨道预设：**2025-11-28 至 2026-11-28（TDB）**。在 Design 模式点击 `Run simulation` 后，选择 `2026 Real Trajectory` 或 `Theoretical Simulation`。前者使用这一年范围的真实初始状态，后者沿用原来的教学轨道和 DIY 物理参数；Simulation 顶部也可通过 `Simulation mode` 切换，切换会重新开始计时。它使用 NASA/JPL Horizons 的真实初始位置和速度，由 REBOUND 近似模拟一年，支持轨道倾角、三维近景跟随、日期显示、时间跳转及年末自动暂停；运行时无需联网。切换保留外观设计，并在当前会话中保留切换前的理论模拟初始条件；从年度文件直接启动且没有理论模式缓存时，理论模式使用原教学默认值。也可 Load `examples/observed-year.json`。数据来源、单位、抽查误差和模型限制见 [年度轨道说明](docs/OBSERVED_YEAR.md)。

默认项目为太阳和八大行星。Design 模式下，点击画面中的行星、全景名称或目录项可进入近景；从一颗行星切到另一颗时经过全景过渡。`Back to system` 返回全景。已经处于同一星球近景时，再点其名称会保留当前状态。近景右键拖动旋转视角，滚轮缩放；镜头过渡期间暂停画面选点和雕刻。

右侧 `Design` 提供各行星已实现的外观参数和可折叠的 `Sculpt brush`。局部雕刻仅在 Design 页且关闭 Inspect/Compare 时生效。`Show baseline` 临时预览默认外观，不撤销编辑；`Reset this body` 会重置该星球设计。地球、火星使用高度图，其他天体包含艺术化形状与纹理设计，适合教学可视化和外观设计。

水星、地球、火星的 `Light and atmosphere` 中新增 `Surface roughness`（0–1，默认 0.7），金星对应 `Radar surface roughness`。低值产生较集中的弱反光，高值呈现更干燥的粗糙漫反射；它使用现有地形法线，不生成新的陨石坑或改变雕刻坐标。地球陆地与添加的极地冰层使用不同表面响应，海洋保留原高光；金星的设置只影响云层下的雷达表面。参数支持 Save、Undo/Redo 与恢复草稿，旧项目缺少该字段时采用默认值。它是用于展示的材质近似，不是测量得到的行星反射率。

地球云层使用带极区衰减的细节光照，薄云和厚云有不同的透光表现；地面云影随太阳入射角变化。沿用 `Cloud cover`、`Cloud drift`、`Cloud altitude` 与 `Cloud shadow` 控制，云量与高度的含义不变。它是现有云壳上的光学近似，没有新增天气模拟或体积云自阴影。

土星环区分受光面与背光面的透光表现：密集环带在背光时更暗，稀薄环带仍可透亮；环带投到球面的阴影也随阳光角度和密度变化。沿用 `Ring density`、`Cassini gap` 和 `Ring tilt offset`，旋转近景可观察两面的差异。环仍是薄面模型，采用受限的光学近似，未模拟真实冰粒散射或新增体积几何。

`Orbit / Physics` 编辑物理参数和初始条件。`Run simulation` 在镜头回到全景后推进 REBOUND 模拟；Simulation 面板可暂停、选择时刻、查看参考轨道和碰撞事件。碰撞演示使用临时地球/火星副本，退出演示恢复原 DIY 项目；演示期间 Save 保存原项目。

画布中的 `Full system` / `Inner system` 可平滑切换全太阳系和内太阳系取景。内太阳系围绕太阳展开，重点展示水星至火星；其他天体及其模拟仍保留。切换时暂停时间推进，结束后恢复此前的播放状态；从单星近景返回时保留之前选择的取景范围。运行期间镜头中心跟随太阳，行星偏离初始轨道后可用 `Reset view` 重新取景。

`Protect sizes` 默认开启：太阳系的有效显示倍率最高为默认值 `1`，避免过度放大太阳时遮住内行星。关闭可恢复项目中设置的夸张倍率。这个选项只调整渲染副本，不改保存文件中的 `Scale`、物理半径、轨迹或碰撞计算；切换时保持模拟跟随近景的相对取景大小。它不能消除所有相遇、环带交叠或视线遮挡。单星设计的相对取景保持一致，演示预设和自定义天体项目沿用原规则。取景选择和保护开关属于本次会话，不写入项目文件。

Simulation 模式下，点击目录中的活动行星、画面中的行星或名称，即可平滑进入近景并持续跟随；也可点击 `Follow selected` 聚焦当前选中行星。镜头以行星的实时位置为中心，右键拖动调整观察角度，滚轮缩放；取景范围按行星显示大小设置，土星近景为环带预留空间。近景保留完整模拟场景、轨迹和模拟光照。重复选择正在跟随的同一行星会保留当前视角和像素检查状态。

跟随期间可继续播放、暂停、调整速度、单步、重置或跳转模拟时刻，镜头随对应状态更新。镜头过渡期间暂停时间推进，抵达后恢复此前的播放或暂停状态。`Back to system` 或 `Reset view` 退出跟随并返回全景；若目标在碰撞中被合并而消失，则自动退出跟随并提示。开启 `Compare` 仍按原规则暂停播放，在同一近景快照上比较采样方法。返回 Design 后退出模拟跟随。

`Impact effects` 可关闭撞击闪光、定向喷射和短暂余热。效果基于合并前记录的接触方向、相对速度以及当前模拟时刻，不影响物理合并或鼠标选取；被前景几何遮挡的效果不会透出。每次最多展示四场活跃撞击，每场最多 26 个光效元素，持续 1.5 个模拟时间单位。表现为艺术近似，未实现物理碎裂、真实撞击坑或永久地貌变化。展示半径可能在实际碰撞前就出现交叠；特效触发以物理事件为准。

合并体还会出现附着在表面的局部高温亮斑，从橙白色逐渐冷却为暗淡痕迹，在 6 个模拟时间单位内消退。亮斑使用撞击当时的自转与轴倾角定位，随表面一起转动，并沿用现有地形、云层遮挡和像素过程记录。金星在可见云顶和内层表面使用各自现有材质，气态行星表现为云顶扰动的艺术近似。每个天体最多保留四处活跃痕迹；天体再次被吸收后，旧痕迹不会自动转移给新合并体。关闭 `Impact effects` 同时移除余热与痕迹。这些不是温度测量或永久撞击坑，不修改 DIY 参数和地形；短回放展示早期冷却，较晚阶段可拖动时间轴查看。

在正常 Simulation 的碰撞列表中点击事件，可平滑移到撞击附近，从事件前最多 0.5 个模拟时间单位开始，以固定 `0.25x` 速度连续播放至撞击后 1.5，再暂停。事件发生在初始时刻时没有撞击前片段。顶部 Play/Pause 控制回放，结束后按 Play 可重播；`Stop replay`、手动选择星球、返回全景、时间跳转、Step、Reset 或返回 Design 会退出回放。普通 Speed 设置保留。Compare 暂停回放；退出 Compare 后可按 Play 继续。碰撞演示在撞击后保留余热阶段再停止，Reset 从头重看。相同事件和快照的特效确定一致，但极高速播放可能跳过短促闪光。

普通模拟最多缓存 16 个完整积分器检查点，包含当前碰撞记录、轨迹及参考轨道，检查点至少间隔 0.5 个模拟时间单位并保留初始状态。时间跳转优先恢复目标之前最近的检查点，再计算剩余时段；重置、返回设计或更换项目会清除缓存。未缓存的长时段仍需积分，检查点不会把未来事件写入当前快照。已观察到的碰撞仍保留为回放书签。不同积分步进可能让事件时刻略有差别，不能保证任意拖动路径逐像素一致；缓存不写入项目文件。

参数编辑、雕刻和重置共享 Undo/Redo，支持 Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z 或 Ctrl+Y；输入框保留文字编辑的撤销行为。撤销跨星球修改时会选中受影响的行星。记录有数量与内存上限，关闭程序后不保留撤销栈。

`Save` 正式更新项目 JSON，`Load` 加载已有项目；有未保存修改时会提示。修改后可生成项目旁的恢复草稿，下次启动可选择恢复或丢弃；恢复后仍需 Save 才更新正式文件。未指定路径时优先使用 `my-solar-system.json`，不存在则新建默认项目。

### 像素检查与比较

普通预览默认启用多级纹理过滤，缩放和斜视时平滑降低细云、环纹及表面颜色的高频细节；高度图与雕刻数据不被重写。球体网格会随屏幕大小在 24×48、48×96 和 96×192 间调整，地形位移逐步混合，近景能显示更细的原始起伏。网格拓扑切换仍可能带来小幅轮廓变化，未使用历史帧累积。

单星设计时，悬停笔刷显示球面上的作用范围，抬高、压低和平滑使用不同颜色。`Design preview` 中的 `Capture reference` 保存当前星球的外观对照；修改后勾选 `Compare reference`，可在相同镜头与光照下左右对比。关闭对比后继续雕刻。对照只在当前会话保留，加载项目会清除；它不替代正式 Save。

`Design preview → Rotate preview light` 可调整设计近景的光源方向和高度，便于观察坡面；进入模拟后仍使用太阳的位置确定光照。预览光照不写入行星设计。

顶部采样菜单提供 `1x`、`4x SSAA`、`4x MSAA`。开启 `Inspect` 后点击画面，右侧进入 Pixel，但 Details 仍需手动展开。直接进入 Pixel 页也会启用取样；手动关闭 Inspect 后会保持关闭并提示重新开启，不会因为停留在 Pixel 页而雕刻地形。

`Compare` 在同一快照上并排比较左右采样方法并暂停播放。点击任一侧，左右放大图同步局部坐标；详细记录与最终 Samples 来自实际点击的一侧。Region 的 9×9、17×17、25×25 表示放大邻域大小；像素内的样本数量由采样方法决定。选中画面后可用方向键微调像素位置。

`Details → Processing history` 按实际顺序展示当前帧选中像素的处理。关闭某一级后，其下级恢复收起；换像素、星球或采样方式时重置。重复点击当前近景星球保留检查内容。

### 测速与后台预览

`Frame cost` 显示 Method、Shades、Time，统计整个视图。画面稳定约 0.25 秒后自动开始：每种方法预热 3 次、正式测量 11 次，取 CPU 渲染耗时中位数；左右交替先后顺序。正式测量关闭详细过程记录，结束后用不计时渲染恢复记录。移动像素或改变放大范围保留有效计时，修改实际场景或采样设置则重新测量。

普通视图交互时临时采用宽高减半的单采样预览，停下后恢复所选质量；Compare、Inspect 和 Pixel 分析保持固定分析分辨率。CPU 渲染在后台执行，图像尚未跟上视角时暂缓画面选点，防止用旧图误操作。当前性能表展示整体 CPU 渲染时间和着色次数。

## 实现与验证边界

球体和环带三角形由 CPU 处理近裁剪、投影、覆盖、透视正确插值、纹理与光照；轨道使用线段处理，大气使用独立射线。云层与星环保留各自透明混合规则。透明层的合成结果与各层处理顺序有关。

单采样在中心着色，SSAA 在各合格样本着色，MSAA 为每个三角形片段/像素共享一次完整着色；一个像素可能包含多个三角形和效果。细纹理与阴影仍可能出现局部跳变。颜色在线性空间合成，最后转换为显示颜色。完整过程只跟踪当前选中的一个像素，最多 4096 条事件。

此前版本在 macOS 上完成 Release 构建，桌面配置 9/9、无界面配置 6/6 自动测试通过；命令行帮助、单图与状态导出、批量对比导出均实际运行通过。该次构建复用了本机已有依赖源码，桌面启动程序已构建并核对路径；验证覆盖构建、自动测试和命令行导出入口，首次联网下载与人工界面复测待补充。

本次 Windows 适配修复了两处兼容问题：`src/simulation.cpp` 引入 REBOUND 头文件时，通过 `_MSC_VER` 判断让 MSVC 使用 `__restrict`，其他编译器保留原来的 `__restrict__`；`tests/studio_document_tests.cpp` 在替换测试文件前显式关闭读取句柄，避免 Windows 文件占用导致测试失败。前者解决编译失败，后者修正测试中的文件生命周期，均不改变运动算法。

模拟近景跟随功能已在 Windows 上完成 Release 构建和桌面配置 9 项自动测试验证，覆盖水星、地球、土星取景、运动跟随、暂停与时间跳转、单步与重置、目标碰撞消失、右键旋转及滚轮缩放。实际窗口已检查地球与土星的近景跟随和返回全景；这不代表全部 Windows 界面功能均已人工验收。

上述兼容修复及模拟近景跟随功能尚未在 macOS 上重新验证。近景跟随使用现有 C++ 与 ImGui 接口，未修改 Metal 显示后端；仍需在目标 Mac 上从源码重新构建、运行自动测试，并检查“进入模拟 → 选择行星近景跟随 → 返回全景”。Windows 的 `.exe` 不能作为 macOS 可执行程序使用。

技术说明保留开发阶段的专项覆盖/光栅器内存与数值检查、界面操作、固定场景图像和多轮计时结果。Linux 原生 GUI 待验证。

多级纹理、近景网格、设计对照/光源/笔刷预览及模拟检查点这一轮，在 Windows MSVC Release 和 WSL Release 均通过 10 项自动测试。实际 Windows 窗口检查了地球雕刻与范围轮廓、修改前后对照、光源方向、切换土星、最大化、设计到模拟过渡，以及普通碰撞事件的 0.25x 回放至自动暂停。此轮尚未重测 macOS，也未给出大型窗口下的稳定帧率保证。
